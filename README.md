# Atlas — Cosmic Browser

Космический браузер на Windows Forms + WebView2 (.NET 10).

## Возможности

- Много вкладок, умная адресная строка, поиск по странице (Ctrl+F)
- История и закладки (шифруются через DPAPI)
- Режим инкогнито
- Встроенный блокировщик рекламы и трекеров с категориями, whitelist и пипеткой
- Менеджер загрузок с паузой/возобновлением
- Кастомная тёмная тема, горячие клавиши, автообновление через GitHub Releases

## Сборка

```bash
dotnet build Atlas/Atlas.csproj
dotnet run --project Atlas/Atlas.csproj
```

Требуется .NET 10 SDK и Microsoft Edge (WebView2 Runtime).

## Автообновление

Настройки → «Репозиторий обновлений»: `werkot20000009853-bot/Atlas-Browser`.
При выходе новой версии браузер предложит скачать и установить обновление.

## Релизы

Релизы публикуются автоматически через GitHub Actions при пуше тега `v*` (например `v1.0.1`).
