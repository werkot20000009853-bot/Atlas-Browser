> ⚠️ **Известное ограничение:** авторизация в **Google / YouTube** через встроенный браузер WebView2 **пока не работает** — Google блокирует вход во встроенных браузерах по соображениям безопасности (страница входа загружается бесконечно).
>
> Кнопка **↗** открывает страницу в системном браузере (Edge/Chrome), но **скорее всего не поможет** — после входа там сессия остаётся в профиле системного браузера, а Atlas использует собственный профиль WebView2. Синхронизации cookies между ними нет, поэтому в Atlas вы по-прежнему не будете авторизованы.

## ⚡ Киллер-фичи по сравнению с обычным браузером

### 1. 🛡️ Блокировщик, который можно «потыкать пальцем»
В обычных браузерах блокировщик — это стороннее расширение, которое надо искать, ставить и настраивать.

В Atlas:
- **Пипетка (⌖)** — клик по рекламе → её домен **мгновенно** добавляется в блокировщик.
- **Косметическая фильтрация** — скрывает сам баннер по CSS-селектору, а не только блокирует запрос.
- **Whitelist** — разрешите рекламу на любимом сайте одним кликом.
- **27 готовых категорий** (Amazon Ads, DoubleClick, Google Ads, Criteo, Taboola, Yandex, поп-апы, биржи SSP и др.).

> Реклама исчезла — вы даже не заметили, как это произошло.

### 2. 🔄 Самообновление из коробки
Обычные браузеры обновляются «когда захотят» и часто требуют системных служб.

В Atlas:
- Проверка **GitHub Releases API** при запуске.
- Скачивание архива, распаковка и запуск новой версии — **полностью автоматически**.
- История версий и релизы — прямо в репозитории.

### 3. 🔐 Данные зашифрованы, а не просто лежат в JSON
Chrome хранит историю в открытой SQLite-базе. Atlas использует **DPAPI** (привязка к учётной записи Windows):
- `history.dat`, `bookmarks.dat`, `blocker.dat`, `settings.dat` — зашифрованы.
- Старые незашифрованные файлы автоматически мигрируют.
- В инкогнито данные вообще не пишутся на диск.

### 4. 🧩 Расширения Chrome без магазина
WebView2 позволяет загружать unpacked-расширения напрямую. Не нужен Chrome Web Store, аккаунт Google или доступ к магазину:
- Установка из любой папки с `manifest.json`.
- Включение/выключение/удаление в один клик.
- Автоматическая перезагрузка вкладок после установки.

### 5. 🌌 Интерфейс, который приятно смотреть
Обычный браузер — это серый прямоугольник. Atlas:
- Анимированная звёздная карта на домашней странице (180+ звёзд, созвездия, небулы).
- Единый стиль **Segoe MDL2** иконок (как в Windows 11).
- Кастомные тёмные диалоги и панель заголовка.
- Всё это — без внешних библиотек, только WinForms + WebView2.

### 6. ⚡ Лёгкость и прозрачность
- Один `.exe` + WebView2 Runtime — никаких фоновых служб.
- Исходный код полностью открыт, 13 тестов, GitHub Actions собирает релизы по тегу.
- Никакой телеметрии, скрытых запросов и «облаков».

## ⚙️ Технические решения

| Решение | Описание |
|---------|----------|
| 🔒 **DPAPI** | Шифрование истории, закладок и настроек с привязкой к учётной записи Windows + миграция старых JSON-файлов |
| 🕶️ **Инкогнито-изоляция** | Отдельный `userDataFolder` во Temp, полностью удаляется при выходе |
| 🔄 **Self-update на месте** | BAT-скрипт дожидается закрытия Atlas, заменяет файлы в папке запуска и перезапускает браузер |
| 🧩 **Расширения** | Загрузка unpacked Chrome-расширений через WebView2 API без магазина и аккаунта Google |
| 🌐 **HttpClient** | Один статический экземпляр с заголовками `User-Agent` / `Accept` для GitHub API |
| 📄 **EmbeddedResource** | `HomePage.html` встроен в сборку, а не захардкожен в C# |
| 🧱 **Partial-классы** | `Form1` разделён на 8 файлов для читаемости |
| ⚡ **Процессы** | `--single-process` по умолчанию выключен (стабильный режим); включается вручную для экономии памяти |
